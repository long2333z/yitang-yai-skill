# 课程与知识：先选一条路

这份是原子 SOP 路由：只在当前任务只需要课程中的一个阶段时使用。若目标是“从课程找方法，再解决真实问题”，直接进入[课程到工作](scenarios/course-to-work.md)。

不要把“找课程”“学方法”“做任务”混在一次读取里。根据当前目标，只打开下面一份 SOP：

| 当前目标 | 读取 |
| --- | --- |
| 从课程、案例、模板、笔记或优秀作业中提炼一个方法 | [课程研究](course-research.md) |
| 用已经提炼的方法处理一个真实小任务 | [课程应用](course-application.md) |
| 只想查课程、作业或笔记，确认对象和内容 | [课程查询](course-lookup.md) |

如果目标还说不清，先用一句话描述“我想解决什么问题”，再选择。一次任务从研究开始时，只有方法卡已经能指导下一步，才进入课程应用。
