# 从课程中挖方法，再把方法用进工作

这一页不是“查到一门课就结束”。它要完成一条完整链路：**找到相关内容 → 提炼一个能用的方法 → 在真实工作中小范围验证 → 保存结果**。

## 先判断你缺什么

| 现在的困难 | 优先找的课程材料 |
| --- | --- |
| 不知道从哪里学、该选哪个方向 | 学习地图或课程分类 |
| 不懂一个概念或方法 | 课程主题和正文 |
| 知道道理，但不知道怎么做 | 案例、模板、清单 |
| 做过但效果不稳，想看看别人怎么练 | 精选笔记、优秀作业、复盘材料 |

先把当前问题写成一句话，例如“我要为一个真实项目定方案，但不知道怎样判断方案是否成立”。不要从“我想看一门课”开始。

## SOP-10：从课程中挖出方法

1. 先用问题、关键词或方法名查课程；需要方向时先看分类或学习地图。
2. 从本次返回取得真实课程或章节 ID。课程、唯一课程 ID 和章节 ID 不是一回事，不能混用。
3. 按当前问题只读最小材料包：先看主题，再按缺口补一份案例、模板、笔记或作业；不需要一次读完整门课。
4. 把内容整理成一张**方法卡**：

   - 它要解决什么问题；
   - 关键动作是什么；
   - 怎么判断做对或做偏；
   - 参考了哪类课程材料；
   - 在什么情况下不该直接套用；
   - 下一次准备拿什么小问题验证。

5. 如果方法卡仍无法指导下一步，回到课程继续找资料，或请教学型 Partner 帮忙解释；不要把搜索标题当成已经掌握。

## SOP-11：把课程方法放进真实任务

1. 选一个足够小、可以在短周期内观察结果的真实问题，不一开始就把方法套到整个项目。
2. 把方法卡连同任务、已有材料、想要的结果和约束交给 Partner，或按方法自行完成这一小段。
3. 观察结果：哪些动作有效、哪些条件不满足、哪些结论只是推测。
4. 根据结果调整方法卡，再决定扩大使用、换方法，还是回课程补知识。
5. 把“场景 → 用了什么方法 → 做了什么 → 得到什么 → 下次怎么改”保存为笔记或对话资产。

## SOP-12：查课程、作业和笔记

1. 先看目标命令的 `--help`，或用 `whyai yitang describe <capability>` 确认当前只读能力。
2. 从本次返回取对象 ID，再读取详情。若快捷命令报“页面不存在”或内容为空，先核对 ID 类型；必要时改用 `whyai yitang call <capability> --param key=value`，并保留错误原文。
3. 作业和优秀作业用于学习、整理和反思，不代写。
4. 查笔记时先说清复用场景。笔记不会自动进入下一次对话；需要时主动选取相关片段带入。

## 做完后确认

这次不只应有“查到的课程”，还应有一张方法卡、一次准备或已经完成的小验证，以及一条可复用的记录。查不到内容或没有权限时，也要说明查了什么、卡在哪里。
