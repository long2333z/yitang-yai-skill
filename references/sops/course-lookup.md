# 课程查询：找到准确对象和内容

适用：只需要查课程、章节、作业或笔记，不需要马上提炼方法。

1. 先运行目标命令的 `--help`，或用 `whyai yitang describe <capability>` 查看当前只读能力。
2. 先做最小范围的搜索或列表读取，再从本次返回取课程、唯一课程或章节 ID。
3. 用正确的对象 ID 读取详情。快捷命令报“页面不存在”或内容为空时，先核对 ID 类型；必要时改用 `whyai yitang call <capability> --param key=value`。
4. 作业和优秀作业用于学习、整理和反思，不代写。笔记不会自动进入下一次对话，需要时主动带入相关片段。

## 做完后确认

说明查了什么、范围多大、拿到了哪个对象，以及内容是否真的解决了当前问题。没有结果或没有权限时，也保留错误原文和已尝试范围。
