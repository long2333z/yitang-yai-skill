# 课程研究：从材料里提炼一个方法

适用：想从一堂课程中找方向、理解方法，或需要案例、模板、笔记来补足做事思路。

## 先把问题说成一句话

写下你要解决的真实问题，而不是课程名称。例如：“我要为一个项目定方案，但不知道怎样判断方案是否成立。”

然后判断缺口：

| 缺什么 | 优先读什么 |
| --- | --- |
| 不知道该从哪学 | 学习地图或课程分类 |
| 不懂概念和原则 | 课程主题、正文或教学说明 |
| 不知道怎么做 | 案例、模板、清单 |
| 想看别人如何练习 | 精选笔记、优秀作业、复盘材料 |

## 只读够用的材料

1. 用问题、关键词或方法名找到课程，再从本次返回取课程/章节 ID。
2. 先读一份最接近问题的主题材料；仍有缺口时，再补一份案例、模板、笔记或作业。
3. 课程数字 ID、唯一课程 ID 与章节 ID 不能互换。对象不匹配或内容为空时，回到当前 CLI 帮助，先确认对象类型和对应的只读能力。
4. 不为“把课读完”而读取。当前问题已经能得到下一步时就停止。

## 做一张方法卡

用自己的话写下：

| 项目 | 要回答的问题 |
| --- | --- |
| 要解决什么 | 这个方法针对的真实问题是什么？ |
| 关键动作 | 先做什么，后做什么？ |
| 判断信号 | 怎样知道做对、做偏或资料不够？ |
| 参考材料 | 来自哪类课程材料？ |
| 适用边界 | 什么情况下不能直接套用？ |
| 小验证 | 下一次准备在哪个小问题上试？ |

## 做完后确认

方法卡能指导一个具体下一步，且能说清来源与边界。不能时继续补一层材料，或请教学型 Partner 帮忙解释；不要把课程标题或一句金句当作方法。
