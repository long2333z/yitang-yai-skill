# 用 Partner 完成一项真实工作

适用：已经选好 Partner，要咨询、研究、整理材料或交付一项结果。

## 先把任务说清楚

| 要准备什么 | 说明 |
| --- | --- |
| 任务 | 要解决什么，最后给谁看或用来做什么决定。 |
| 材料 | 已有事实、数据、文件和已经尝试过的做法。 |
| 结果 | 希望得到什么形式、做到多细、什么时候要。 |
| 约束 | 来源范围、隐私、时间、不能做什么，以及谁来确认。 |

缺少的信息会改变结论时，先补问，不急着开始。

## 开始、修正、交付

1. 开始前确认 Partner、会话、知识库/网页工具和附件都对。
2. 复杂任务先请 Partner 复述目标、说出缺口和计划；需要方法时，先学习或校准，再派正式任务。
3. 说明资料来自课程知识、公开网页还是两者。工具已打开不等于已使用，结果里要能看出来源。
4. 上传文件前确认文件正确、可读且已获授权。复杂表格、扫描件或图片的关键结论要回看原件。
5. 想修改答案时，说清“改哪里、为什么、受什么限制、希望变成什么样”，不要只说“再好一点”。
6. 交付前分开写：已经确认的内容和来源、自己的判断、仍待确认的事项、下一步建议。

## 保存有用结果

保存时写明场景、原问题、输入条件、结论、来源线索和适用范围。下次使用时，主动带入真正相关的片段；笔记不会自动成为新对话的上下文。

## 做完后确认

结果符合原先想要的形式，关键来源能回查，限制和下一步清楚。涉及重要决定时，保留人工确认。
