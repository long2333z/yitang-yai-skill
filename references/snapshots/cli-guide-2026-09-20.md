# 一堂 CLI 使用指南：要点整理

## 使用边界

- CLI 面向已具备有效 YAI 权益的用户；读取作业、Candy、笔记以及调用 Partner 都可能消耗权益。
- `whyai --json billing access` 才是 CLI 任务的资格判断：通用赠送额度不等于 CLI 可用。
- 本快照只抽取可操作的规则。命令的当前参数、返回字段和实际结果必须由 `--help` 或本次运行确认，不能只凭文档臆测。

## CLI 最小验证链

1. **可执行**：确认 `whyai --version` 可运行；若找不到命令，先处理安装或 PATH，不把它误报为登录失败。
2. **命令契约**：根据任务运行相关 `--help`，以当前帮助决定参数和写操作风险。
3. **身份与环境**：读取 status/account；期望 Gateway 为 `ai.yitang.top`、环境为 `prod`。
4. **资格**：有读取或对话需求时读取 `billing access`，记录 eligibility、reason、token 事实。
5. **实际读操作**：用范围最小的课程/作业/笔记/Partner 查询验证真实可用性；登录成功不是业务调用成功。

## 命令与数据控制

- 列表先用默认范围；只有任务确实需要时才扩大 `--all`、时间范围或分页。
- 所有课程、章节、作业、笔记、Partner、会话 ID 都以本次 CLI 返回为准；用户口述名称不能替代 ID。
- `--no-memory` 只关闭记忆，不代表不创建会话或消息；已有会话加 `--partner` 也不等于切换角色。
- 文件参数会上传并创建远程消息/会话，属于有影响动作；先确认文件、目标 Partner、输出和授权。

## 故障分流

| 现象 | 先做什么 | 不应做什么 |
| --- | --- | --- |
| 找不到 `whyai` | 检查安装状态与 PATH，再按正式安装说明修复。 | 直接当作账号或 Gateway 问题。 |
| 浏览器授权后无结果 | 回到终端复查 status，再执行一个最小只读查询。 | 仅凭浏览器已跳转宣称可用。 |
| Gateway/环境不符 | 停止业务调用，按正式 Gateway 重新登录并验证。 | 在非正式环境执行真实任务。 |
| 权益错误 | 检查 account 与 billing access，保留错误码/原文。 | 用泛额度或猜测代替资格结论。 |
| 调用错误 | 保存目标、命令、脱敏错误、时间和截图（如有）后反馈。 | 抹掉原始错误后反复猜参数。 |
