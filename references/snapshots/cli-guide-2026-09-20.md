# 一堂 CLI 使用指南：本地快照

> 这是基于官方页面当前可见渲染内容整理的分析快照，不替代页面本身，也不替代本机 CLI 的实时 `--help` 和服务端返回。

## 页面定位

页面面向第一次使用一堂 CLI 的用户。页面明确说明：CLI 需要 YAI 思考版及以上且订阅有效；使用 CLI 会消耗套餐额度，读取作业、Candy、YAI 笔记以及调用 AI Partner 都可能消耗额度。

## 目录快照

- 01 一堂 CLI 与快速上手：CLI 是什么、交给 Agent 安装、确认安装和登录、第一次使用。
- 02 CLI 进阶使用：日常找笔记、找作业、找 Partner、推荐课程；把多种能力接起来；接入日常工作流程；美好的一天。
- 03 常用命令速查：版本/帮助/登录、套餐与用量、课程/作业/笔记、Partner 调用、回看结果并交给下一步。
- 04 遇到问题怎么办：命令或连接不通、反馈、常见问题。
- 05 更新与版本记录：查看版本、升级版本、更新日志。

## 可直接引用的安装与登录路径

官方页面给出的 Agent 指令是：

```text
请访问 https://ai.yitang.top/cli，按照页面中的正式环境说明安装 YAI CLI，然后运行：
whyai --version
确认最新版本。登录时使用：
whyai login --gateway https://ai.yitang.top
确认终端显示的 Gateway 是 ai.yitang.top，再引导我完成浏览器授权。
```

页面同时提示：浏览器没有自动打开时，应使用本次登录生成的授权链接；授权页面可能跳转到统一登录，但连接环境以终端显示的 Gateway 为准，过期链接需要重新发起登录。

## 对核心 SOP 的证据贡献

1. **环境准入**：安装、版本、帮助、Gateway、登录、套餐和额度必须单独成门，不把“命令可执行”误认为“业务资格已确认”。
2. **学习与知识**：课程、作业、笔记是并列业务入口；课程和作业不能只依赖自然语言推测，应进入真实命令和真实 ID 流程。
3. **Partner 工作**：找 Partner、调用 Partner、保存结果、把结果交给下一步，是一个完整任务链，不是单次问答。
4. **任务执行与资产**：官方目录把“回看结果，交给下一步”单列出来，支持任务闭环和结果沉淀 SOP。
5. **对话与故障**：官方把命令连接故障、版本升级和常见问题列为独立分支，支持单独的故障收敛 SOP。

## 当前事实边界

页面目录和示例说明产品意图；命令是否存在、参数如何写、返回字段和环境状态，仍以当前 `whyai --help`、子命令帮助和实际 JSON 返回为准。
