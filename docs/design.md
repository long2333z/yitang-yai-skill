# 设计文档

## 目标

让用户把一堂 YAI 的课程方法、Partner 协作和个人知识资产用于真实工作。`whyai` CLI 提供连接、读取和调用能力，但不替代方法学习、任务判断和人工确认。

## 触发边界

适合：一堂 YAI 专属的课程研究、课程应用、Partner 协作、会话与资产任务。

不适合：泛学习咨询、与一堂无关的 AI/Partner 任务，或把课程回答直接当作业务事实。

## 关键设计选择

1. 运行期从任务出发，而不是从工具或资料名称出发。
2. 课程任务拆成研究、应用、查询：研究产出方法卡，应用产出小验证，查询只负责准确对象。
3. CLI 返回和官方实时页面优先于本地资料；本地资料解释“为什么”和“下一步”。
4. 上传、创建、分享、删除和发布必须在用户明确同意后执行。

## 质量标准

一次运行至少能回答：这次想解决什么、依据什么方法、实际做了什么、哪些已经确认、下一步怎么做。
