# 课程内容怎么挖：运行时观察

## 课程不是一篇文章

本次只读验证确认，课程内容可分为几层：

1. **学习地图**：帮助判断当前问题应该先学哪一块。
2. **课程主题与正文**：说明一个方法解决什么问题、背后的原则是什么。
3. **案例、模板和清单**：把抽象方法变成可以参考的做法。
4. **精选笔记和优秀作业**：展示真实练习如何把方法用出来。

因此，找课程时不要只问“有没有一篇文章”，而要先问“我现在缺的是方向、方法、样例，还是一份可直接练习的模板”。

## 已验证的读取能力

当前 CLI 提供课程搜索、分类、已学课程、课程信息、章节/材料、最近学习材料等只读能力。课程资料可能以地图、案例、模板、笔记、作业或直播回放出现。

对象 ID 可能有不同形式；课程数字 ID、课程唯一 ID 和章节 ID 不能互相替代。先从本次返回取 ID，再用当前帮助或 `whyai yitang describe` 确认调用方式。

如果课程快捷命令返回“页面不存在”或章节为空，不要直接判定课程没有内容：先检查使用的对象类型和 ID，再用 `whyai yitang call <capability> --param key=value` 读取同一只读能力，并保留错误原文。

## 一张课程方法卡

每次从课程中拿走一个方法时，至少写下：

| 项目 | 要回答的问题 |
| --- | --- |
| 要解决什么 | 它针对的真实问题是什么？ |
| 关键动作 | 从第一步到最后一步要做什么？ |
| 判断信号 | 怎样知道自己做对了、做偏了？ |
| 参考材料 | 来自课程主题、案例、模板、笔记还是作业？ |
| 适用边界 | 什么情况下不该直接套用？ |
| 小实验 | 下一次工作里准备拿哪一小段来验证？ |

方法卡不是课程摘要。它的价值在于让下一次真实工作可以开始一次小实验，而不是重新读一遍资料。
