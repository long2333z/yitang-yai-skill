# 一堂 YAI Skill：维护文档

这里是维护者在设计、改造和复核 Skill 时阅读的文档，不是运行时知识。`SKILL.md` 和 `references/` 不应链接到本目录。

| 文档 | 什么时候看 |
| --- | --- |
| [设计文档](design.md) | 调整定位、触发边界、资料分层或用户体验时。 |
| [方案文档](solution.md) | 调整核心工作流、SOP 责任或运行资料索引时。 |
| [架构文档](architecture.md) | 调整目录、资料加载关系、安装副本或验证边界时。 |
| [迭代记录](iterations/) | 续做已有优化、追溯判断和验证证据时。 |

维护完成后，运行 Creator preflight、链接检查和受影响的真实 CLI 只读验证；不要把本目录内容当作运行期指令。
