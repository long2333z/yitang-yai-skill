# SOP-30：知识校准后的实际任务执行

适用：已选定 Partner，准备咨询、生产、研究或整理一项真实任务。

## 任务包

按下列顺序组织输入；缺项且会改变结论时，先请 Partner 或用户补问：

1. **任务**：要解决什么，决策或交付对象是谁；
2. **已有材料**：事实、数据、文件、已尝试内容及其可信度；
3. **目标输出**：格式、颗粒度、期限、验收人；
4. **约束**：来源范围、隐私、预算/时间、不可做事项和人审点。

## 执行链

1. 选定会话并复核 Partner、模型、知识库/网页工具、附件和要求。
2. 要求先复述任务、指出缺口和执行计划；复杂任务先做知识/方法校准，再正式派工。
3. 明确来源范围：课程知识、公开网页或两者。工具“已开启”不等于“已使用”，要求返回中体现来源或工具记录。
4. 上传文件前确认文件正确、可读且用户已授权；等待处理完成后再下任务。复杂表格、扫描件或图像的关键结论要回看原件。
5. 收到答案后按对象/条件精确修订，例如补一个约束、改输出格式、区分事实与推断；不要只说“再好一点”。
6. 在交付前要求结果分层：事实与来源、推断、假设/未决项、建议的下一步。高影响决定由人确认。

完成标准：交付物符合目标输出，来源/限制可见，关键事实经过回看；否则保留未决项并继续或转交。

# SOP-31：把结果沉淀为可复用资产

适用：保存答案/对话、创建笔记、导出资料，或为下次任务准备复用包。

1. 只保存有明确复用价值的结果；写清场景、原问题、输入条件、结论、来源线索、未决项和适用边界。
2. 保存后记录笔记或会话的定位信息，并核对标题、内容和保存时间；需要分类/移动时再验证目标位置。
3. 下次使用时，主动挑选相关片段并重新说明新任务。保存的笔记不会自动进入未来对话上下文。
4. 涉及个人、业务或受限材料时，最小化保存与外发范围，遵循用户授权。

完成标准：资产可定位、可理解、可判断是否适用；不是只有一个无说明的链接或标题。
