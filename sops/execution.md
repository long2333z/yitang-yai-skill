# 一堂 CLI 任务执行与资产 SOP

## SOP-30 单任务闭环

适用：用户给出一个真实工作问题，希望从背景输入走到可用产出。

1. 收集最小背景：问题、目标、约束、已有材料、成功标准和输出格式。
2. 需要方法/知识时转到 [学习与知识](learning.md#sop-10-课程与知识检索)；需要专家角色时转到 [Partner 工作](partner.md#sop-20-partner-选择与调用)。
3. 用一条清晰指令完成第一轮，不把多个未排序目标混在同一轮；本地材料只有在用户明确指定后才使用 `--file`。
4. 检查回答是否覆盖目标、依据、假设、风险和下一步；“正确但不可执行”视为未完成。
5. 通过同一 `conversation_id` 做一次聚焦追问，把缺失条件、格式或判断标准补齐。
6. 将最终结果交给用户验收：结论、待办、未验证项、使用过的课程/Partner/文件来源分别列出。
7. 用户需要复用时执行 SOP-31；需要多角色协作时执行 [Partner 接力](partner.md#sop-21-多-partner-接力)。

完成标准：产出满足用户定义的成功标准，追问已收敛，未验证边界清晰；不把模型回答完成冒充业务执行完成。

## SOP-31 笔记与资产沉淀

适用：把回答、课程要点、作业复盘或任务成果保存为可找回、可复用的个人资产。

1. 列出候选笔记：`whyai --json notes list`；按实际支持的文件夹参数缩小范围。
2. 读取真实 `NOTE_ID`：`whyai --json notes get NOTE_ID`。
3. 从对话保存时，先完成 [对话与故障](conversation.md#sop-40-对话管理)，确认要保存的最终版本和标题。
4. 用户明确要求新建笔记时，使用 `whyai notes create --title "标题" --content @本地文件路径`；确认本地内容不包含不应上传的敏感信息。
5. 需要本地备份时先查 `whyai notes --help`，再使用当前版本支持的导出/下载命令。

笔记至少保留：问题/目标、关键结论、依据或来源、适用边界、下一步和更新时间。

完成标准：笔记有真实标题/ID；保存动作的远端影响已报告，内容可被后续搜索和复用。
