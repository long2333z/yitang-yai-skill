# 学习、课程和笔记

这一页处理三类事：先弄懂一个方法；查课程或作业；找以前保存的笔记。

## 想先学再做

1. 先说清楚：你要解决什么问题、已经知道什么、希望参考课程知识还是公开资料。
2. 用关键词或方法名找课程内容。搜索结果只是入口，不等于完整结论。
3. 需要精确内容时，从本次结果里取课程或章节 ID 再读取详情。
4. 给出三样东西：可以采用的方法、适用范围、还缺什么信息。缺的信息会影响方向时，先补齐再开始做事。

## 查课程或作业

1. 先看目标命令的 `--help`，再按关键词查询。
2. 从当前结果中取课程、章节、作业或答案 ID；再按 ID 看详情。
3. 作业列表先读一页。只有确实需要时，才扩大日期范围、分页或使用 `--all`。
4. 说明查了什么、范围多大、得到哪些和任务有关的内容。作业只用于学习、整理和反思，不代写。

## 找笔记

1. 先说出要复用的场景和关键词，再从最小范围的笔记或文件夹开始找。
2. 用本次返回的 `NOTE_ID` 读取内容，确认它是否真的适合当前任务。
3. 笔记不会自动带入下一次对话。下次使用时，主动选出相关片段，并重新说明新任务。

## 做完后确认

能说清来源、ID、查询范围和结果是否适用；如果没找到或没有权限，也直接说明。
