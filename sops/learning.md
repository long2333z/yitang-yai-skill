# SOP-10：方法校准与课程知识

适用：用户问课程概念、方法、案例、想先学再做，或执行任务前知识边界不清。

## 判断与步骤

1. 先分类：目标是**理解课程/方法**，还是**交付一个具体任务**。前者走本 SOP，后者可先走 `partner.md` 的 SOP-20；两者并存时先校准方法。
2. 写清问题、已有认知、希望使用的来源（课程知识、公开网页或两者）和不应假定的边界。
3. 先以关键词/方法检索课程知识；不把搜索结果或 Canvas 线索当成完整课程事实。
4. 要精确内容时，用本次返回的真实课程/章节 ID 读取详情。范围默认最小，避免无目标的全量拉取。
5. 输出“方法/概念、适用边界、来源、尚缺信息”。若缺口会改变任务方向，先追问或请用户确认，再派发实际任务。

完成标准：得到可用于下步的共同理解，或明确说明因资料/权限/目标缺失无法校准；不能把未经确认的 Partner 回答伪装成课程事实。

# SOP-11：课程与作业的受控查询

适用：搜索/读取课程、章节、课程导航、作业或答案。

1. 先跑目标命令的 `--help`，再按关键词搜索或列举最小范围清单。
2. 从当前返回取得课程、章节、作业或答案 ID；再用 ID 读取详情。
3. 作业列表默认只读一页；仅在任务明确需要时使用 `--all`、日期范围或分页。`--since` 优先给准确边界。
4. 记录来源对象、查询范围、返回时间和与任务有关的事实；不提供代写作业服务。
5. 若结果要进入工作流，附上“事实/我的反思或推断/待确认”的分层。

完成标准：返回可复查的真实对象与范围，或者清楚说明权限、权益、ID 或时间范围的阻断。

# SOP-12：笔记检索与受控读取

适用：查找已保存的笔记、文件夹或按 ID 读取笔记。

1. 先说明要找的复用场景和关键词，列举最小范围的笔记/文件夹。
2. 用本次返回的 `NOTE_ID` 读取内容；确认是否真的适用于当前任务。
3. 笔记不是自动上下文。需要在下一次对话使用时，主动选取、粘贴或上传相关片段，并重新写明任务和约束。

完成标准：定位到可复查笔记及其适用条件，或明确没有找到/无权限。
