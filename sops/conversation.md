# SOP-40：会话续聊、改写与分支

适用：继续同一任务、纠正输入、尝试备选方向，或判断是否另开会话。

| 观察到的变化 | 正确动作 |
| --- | --- |
| 同一目标，只补条件、改格式、纠正理解 | 留在同一会话，引用具体对象和条件续聊。 |
| 原始问题/材料有错，需要改起点 | 编辑原消息或重新发起；确认新答案基于正确输入。 |
| 目标、核心对象或主材料已经改变 | 新开会话，并重新提交任务包。 |
| 要在保留当前上下文下比较另一条路线 | 从合适回答建立分支；先核对继承的材料，再给不同目标。 |
| 生成过程发现问题 | 停止生成后给出具体修正或重新生成；不要在错误上下文继续叠加。 |

步骤：

1. 先列出当前会话的目标、Partner、已验证事实和未决项。
2. 按表选择续聊、改写、新会话或分支；通过 CLI 时使用本次帮助确认命令和真实 conversation ID。
3. 续聊指令必须说明“改什么、为什么、受什么约束、希望如何验收”。
4. 更新会话标题，使它能表达任务/项目与关键区分项。

完成标准：会话边界清楚，后续读者能知道为什么沿用或切换上下文。

# SOP-41：导出、分享与删除前的保全

适用：收藏、导出 Markdown、创建分享链接、删除会话/消息。

1. 先确认范围：当前消息、整段会话还是相关笔记；删除前先保存真正需要的结果。
2. 导出 Markdown 后打开并检查。官方说明中图片不嵌入 Markdown，必要时单独保存并标注原始文件位置。
3. 分享前检查全会话内容、附件、隐私和接收范围；分享链接可能让持链路者查看完整会话。需要固定副本时选择导出，而不是只发动态链接。
4. 删除是不可逆高影响动作：说明对象和影响，获得明确授权；如当前平台有收藏限制，先处理收藏状态。

完成标准：导出/分享/删除的对象、位置、可见范围和授权状态可以回查。

# SOP-42：命令与对话异常的证据化处理

适用：CLI 返回错误、Partner 产出与来源不符、文件解析异常或结果不可验证。

1. 停止扩大影响范围，保留目标、时间、命令或操作、脱敏错误、相关 ID 和截图（如有）。
2. 先按 `access.md` 确认是否为可执行、登录、Gateway、环境或权益问题。
3. 若是内容问题，回到 SOP-30 复核任务包、来源开关、附件可读性和事实/推断边界。
4. 仅在当前帮助支持时调整参数；仍不能闭环则带完整证据反馈，不编造成功结果。

完成标准：错误被定位到可复现阶段，或明确缺少何种外部信息/授权。
