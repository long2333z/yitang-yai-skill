# 继续、分支和整理对话

适用：继续一段对话、改输入、换方向、导出、分享、删除，或排查异常。

## 该继续还是另开

| 情况 | 怎么做 |
| --- | --- |
| 目标没变，只是补条件、改格式或纠正理解 | 留在原会话继续。 |
| 原问题或材料错了 | 改原消息，或重新发起。 |
| 目标、主要对象或主要材料变了 | 新开会话，并重新说明任务。 |
| 想保留当前背景，同时试另一种方案 | 建分支，再提出新方向。 |
| 生成过程发现明显问题 | 停止后说明具体修正，再继续或重试。 |

续聊时要说清：改什么、为什么、受什么限制、最后想看到什么。会话标题也要能让人一眼看出主题。

## 导出、分享和删除

1. 先确认处理的是一条消息、整段会话还是相关笔记；删除前先留住真正需要的结果。
2. 导出 Markdown 后打开检查。图片不会嵌入导出文件时，要另外保存原件。
3. 分享前检查完整内容、附件和接收范围；持链接的人可能看到整段会话。要固定版本时，用导出文件。
4. 删除前说明对象和影响，得到明确同意。

## 遇到错误

保留目标、时间、命令/操作、脱敏错误和相关 ID。先回到[环境准入](access.md)检查命令、登录、Gateway 和权益；再检查任务、资料来源和附件。只有当前帮助支持时才改参数。

## 做完后确认

能说明为什么继续、另开或分支；导出、分享或删除的对象和范围也能找回。
