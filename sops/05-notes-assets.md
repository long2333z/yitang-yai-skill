# SOP-05 笔记与资产沉淀

适用：把回答、课程要点、作业复盘或任务成果保存为可找回、可复用的个人资产。

## 操作

1. 列出候选笔记：`whyai --json notes list`；按实际支持的文件夹参数缩小范围。
2. 读取真实 `NOTE_ID`：`whyai --json notes get NOTE_ID`。
3. 从对话保存时，先完成 [对话管理](08-conversation.md)，确认要保存的最终版本和标题。
4. 用户明确要求新建笔记时，使用 `whyai notes create --title "标题" --content @本地文件路径`；确认本地内容不包含不应上传的敏感信息。
5. 需要本地备份时，先查 `whyai notes --help`，再使用当前版本支持的导出/下载命令；不要猜测参数。

## 资产结构

笔记至少保留：问题/目标、关键结论、依据或来源、适用边界、下一步和更新时间。原始回答不等于整理后的资产，必要时先改写再保存。

## 完成标准

已读取或创建的笔记有真实标题/ID；保存动作的远端影响已报告，内容可被后续搜索和复用。
