# 一堂 CLI 官方引用\n\n## 权威来源\n\n- [一堂 CLI 使用指南](https://yitanger.feishu.cn/wiki/XoFcwMmotigm7Ikv4RQc9TfQn0g)\n\n该页面是本 Skill 的外部参考，不是本 Skill 的内容副本。\n\n## 读取时机\n\n仅在以下情况读取页面：\n\n- 当前 CLI 的 `--help` 没有解释任务所需的命令或授权行为；\n- 用户要求了解一堂 CLI 的使用背景、正式环境说明或登录流程；\n- 需要确认文档中的操作意图，再用本机 CLI 做实际验证。\n\n## 事实优先级\n\n1. 当前本机 `whyai --help`、对应子命令帮助和实际返回，决定命令是否可执行。\n2. 飞书页面补充用户-facing 的使用说明和流程背景。\n3. 页面与 CLI 实际行为不一致时，保留原始命令输出，报告差异；不把页面示例当成当前版本的强制参数。\n\n## 引用边界\n\n只提取完成当前任务所需的最小信息，并在结果中给出来源链接。不要把整页正文、长段落或与当前任务无关的命令清单复制进 Skill。
